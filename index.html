    How it works

    1. Understand — rows, types, missing values and duplicates are analyzed.
    2. Map — synonyms, fuzzy matching and value checks convert any layout to a standard schema.
    3. Score — an XGBoost model returns a fraud probability for every transaction.
    4. Report — statistics on screen and a CSV with Prediction and Fraud_Probability.

    Required columns: transaction type, amount, sender balance before and after. API: POST /api/predict with JSON.

    Trained on PaySim (synthetic data). Scores do not guarantee accuracy on real bank data.
